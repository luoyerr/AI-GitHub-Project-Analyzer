# 学习路径 Prompt

## 任务描述

为新开发者制定项目学习路径。

## 输入变量

- `repo_name`: {{repo_name}}
- `directory_tree`: {{directory_tree}}
- `key_files`: {{key_files}}
- `sampled_code`: {{sampled_code}}

## 输出要求

提供以下内容：

- 建议阅读顺序
- 优先学习的模块
- 前置知识要求
- 分阶段学习计划
- 关键代码位置指引
- 常见问题解答

## 约束条件

- 考虑不同水平的开发者
- 从简单到复杂递进
- 提供具体的文件路径
- 标记难点和重点
- **重要**：必须基于实际的项目信息进行分析，不要返回“请提供xxx”之类的提示
